審査: インパクト30 / デモ25 / Claudeの活用25 / 深さと実行力20。デモは動画1本で、事前録画。
設計メモ（docs/design.md）のデモの節を、画面と作業に結びつけて具体化したもの。
画面の数字は、合成データA（旅館「雪待荘」）を Claude API で解析した結果の値（2026-11-07 時点）。

## 方針
- 冒頭は事業者の困りごとで始める。分析画面で始めない。
- 一番見せたいのは「AIが探したのに、ページがなかった」が数字で見え、Claudeが原因を判断し、下書きが出て、人が承認する流れ。
- 画面に出る旅館・サービスはすべて架空。画面の隅に「架空のサイト・合成データ」と出す。
- 「AIに聞くと旅館が出てこない」の場面で、実際のAIの回答を作って見せない（でっち上げになる）。文字のカードで困りごとを語る。
- 下書きはClaudeが実際に書いたものだけを見せる。見本の下書き（`ashiato/sample.py`）をClaudeの出力として見せない。
- 前後の比較は、「直したあとのログ」を別に入れたときだけ出る。before だけでは出さない。
- 動画は3分以内（超えると減点）。台本は2分55秒で、5秒の余裕を持たせる。ナレーションは、1秒に5字前後を目安に、枠に収める（Kei は話すのが速いので、多めにしてある。声に出して、必ず時間を測る）。期間中に作った機能だけを見せる。

## 録画の準備（11/7）
1. 準備: `set -a; source .keys/.env; set +a`（キーを環境変数に入れる。画面に出さない）。
2. 本番で使う下書きは、Claude API で実際に取った出力（`examples/ryokan/claude_response.json`、9件、反映のしかた付き。検証は有効9件・拒否0件）。
   生成に1〜2分かかるので、録画では `--live` ではなく、保存した返答を使う:
   `python3 scripts/serve.py data/synthetic/ryokan/site/before 雪待荘 --response examples/ryokan/claude_response.json`
   （この返答は、このデータから実際に Claude が書いたもの。概要文に「録画は、保存した実際の出力を使った」と書く）。
   画面の件数・内訳は、この返答で出たものを読む（承認する下書きは、/access、/plans/winter の転送、robots.txt など。続きの話題の候補は、/blog/matsuri-2026-stay と /plan/winter/faq）。
3. `--live` の実行そのものを見せたいときは、待ち時間（1〜2分）を編集で詰める。詰めたことを概要文に書く。
4. 前後の比較は、レポートの下の欄に `data/synthetic/ryokan/after.ndjson` を入れる。
5. 目2の欄は `--live` で起動したときだけ出る。ログの場面（0:08〜2:24）は `--response` で撮り、いったん止めて `--live` で起動し直して目2の場面（2:24〜2:42）を撮り、編集でつなぐ。
   目2の場面は、`--live` で起動した画面で「デモ用の架空のサイトで試す」を押す（AIの答えのチェックは外したまま。実在の事業者名が出るおそれがあるため）。先に1回通して、成功した画面で撮る。
6. 画面の隅に「架空のサイト・合成データ」と出す（編集で文字を重ねる）。

## 録画の注意
- ライブ実行は止まりうる。Claudeの実行は先に1回通して、成功した結果を保存し、画面はその結果で動かす。
- 数字は画面の値をそのまま読む。ナレーションの「3割」は、画面が 713 回中 219 回のとき 30.7%。
- 実在の事業者名、実ログ、実際の集計値は画面に出さない。API キーも、画面に出さない（`.keys/` を開かない）。
- 「承認」はブラウザの中の印だけで、サイトには何も書き込まない。そう言う。

## 概要文・デモで正直に言うこと
- Claude（`claude-opus-5-5`）の呼び出しは、画面の `--live` も、保存した返答（`examples/ryokan/`、9件）も、Claude API。
  Managed Agents は、合成データのブリーフで1回、実行した（古い指示文、13件、検証に1回で通った）。その後、指示文を変えたので、
  クラウドの Agent は古いまま。Managed Agents は合成データでしか実行していない。
- 目2（サイトの公開ページの診断）は、合成データの旅館で、実際の API で1回動かした。目3（AIの答え）は、実際の API での確認がまだ。確認できた分だけを書く。
- 「仕込んだ7つの問題すべてに判断が出た」は、合成データ（仕込んだ側が正解を知っている）で、Claude API の1回の実行（9件）を、設計メモの仕込み7つと照らした結果。実サイトでの正解率ではない。集計はコードが数え、Claudeはその集計をもとに判断して書いた。
- デモのサイトとログは、すべて架空の合成データ。実ログは使っていない。
- デモのデータは、すべて合成データ。直したあとも、仮説にもとづいて作ったシナリオ（ChatGPTの利用が全体に増えるので、AIの要求は全体に約15%増える。提案したページ宛は、さらに上乗せされる。新しいURLの探索は続く。AIの回答から来た人も増える）。
  実際の効果を示すものではない。断りは、全体に1回（画面の隅の「架空のサイト・合成データ」と、説明欄）。特定の数字だけを、特別に断らない。
  ナレーションでは、「ページを直したから、AIの要求が増えた」と、原因を言わない。
- 前後の比較は、直す前と直したあとのログを、別々に入れたときに出る。
